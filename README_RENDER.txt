LA ESPADA DE LA FE - RENDER STATIC SITE

IMPORTANTE: NO subas este ZIP como un archivo dentro de GitHub.
Descomprime el ZIP y sube las carpetas/archivos resultantes al repositorio.

Estructura esperada del repositorio:
/public
  index.html
README_RENDER.txt

Configuracion en Render:
Service Type: Static Site
Root Directory: dejar vacio
Build Command: echo "Static site ready"
Publish Directory: public
Branch: main (o la rama donde subiste los archivos)

Luego selecciona Manual Deploy > Deploy latest commit.
